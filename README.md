# 財報忙季人力規劃工具

純前端的財報忙季人力預估與即時計算工具。Excel 會在瀏覽器內讀取與計算，不會上傳到後端。

## 本機執行（Windows／macOS）

### 1. 安裝 Node.js

請先安裝 Node.js 22.13.0 以上版本：<https://nodejs.org/>

安裝完成後，確認版本：

```bash
node --version
npm --version
```

### 2. 下載專案

在 GitHub Repository 頁面按 `Code` → `Download ZIP`，解壓縮到電腦；或使用 Git：

```bash
git clone https://github.com/chos1npc/financial-planner.git
cd financial-planner
```

### 3. Windows 啟動方式

開啟 PowerShell，進入專案資料夾：

```powershell
cd "C:\你的路徑\financial-planner"
npm.cmd install
npm.cmd run dev
```

如果你的 PowerShell 沒有執行原則限制，也可以使用 `npm install` 與 `npm run dev`。

### 4. macOS 啟動方式

開啟 Terminal，進入專案資料夾：

```bash
cd /你的路徑/financial-planner
npm install
npm run dev
```

### 5. 開啟網站與停止伺服器

看到終端機顯示啟動成功後，用瀏覽器開啟 <http://localhost:5173>。要停止網站，在該終端機按 `Ctrl+C`。

Excel 檔案只會在瀏覽器本機讀取，不會上傳到伺服器；每台電腦都需要自行安裝 Node.js 與依賴套件。

## 功能一：人力預估

適合忙季開始前，用上一季的每日公告量推估本季負荷。

### 操作方式

1. 在 Step 1 設定人員。預設 4 人；每人分別輸入「一般產業每日本數」與「非一般產業每日本數」。非一般填 `0` 代表該人不能做非一般產業。
2. 在 Step 2 輸入「歷史 T 日」、「本季 T 日」與預計完成日。T±N 只按照工作日計算，週六、週日跳過；畫面最多顯示到 T+5。
3. 在 Step 3 手動輸入每日數量，或匯入 XLSX/XLSM。
4. 匯入後檢查 T 日映射、每日待辦、預估清完日與所需人力。

### 預估檔案格式

匯入的 Excel 會優先讀取工作表 `2025Q2本數`；若沒有，會讀取名稱包含「本數」的第一個工作表。第一列必須是欄位名稱，第二列起放資料。

必要欄位：

| 欄位 | 可接受名稱 | 說明 |
| --- | --- | --- |
| 公告日期 | `ann_date`、`公告日`、`公告日期` | 每筆財報的公告日 |
| 公司碼（建議） | `comp_id`、`公司碼`、`公司代碼`、`公司代號` | 用來去除同一家公司重複資料 |

日期可使用 Excel 日期、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD` 或 `MM/DD`。使用 `MM/DD` 時會以 2025 年補足年份。

## 功能二：即時計算

適合忙季進行中，依公司公告清單與實際完成紀錄計算每日進度。

### 操作方式

1. Step 1 設定人員與兩種產業的每日處理量。
2. Step 2 設定忙季開始日、T 日與結束日；畫面會顯示每個日期的星期，週末不建立一般工作日。
3. Step 3 先匯入「公司財報清單」，再匯入「人力完成紀錄」。兩個檔案是分開的。
4. 選擇 `annyymm` 與 `quarter` 後匯入公司清單，再按「依人名匯入完成日期並更新實績」。
5. 查看每日收到、完成、當日剩餘、累計剩餘，以及一般／非一般產業統計。

### 公司財報清單（公告日）

檔案格式為 `.xlsx` 或 `.xlsm`。第一列必須是欄位名稱，資料從第二列開始。

必要欄位：

| 欄位 | 可接受名稱 | 說明 |
| --- | --- | --- |
| 公司碼 | `comp_id`、`公司碼`、`公司代碼`、`公司代號` | 比對公司與去除重複的主要欄位 |
| 公司名稱（公司碼沒有時使用） | `comp_sname`、`公司名稱`、`公司簡稱`、`公司名` | 公司碼空白時作為識別依據 |
| 財務年月 | `annyymm`、`財務年月` | 例如 `2026-06-01`；請保持同一檔案格式一致 |
| 季別 | `quarter`、`季別` | 例如 `2` |
| 公告日 | `公告日1`、`公告日`、`財報日` | 空白代表尚未公告 |

選填欄位：

| 欄位 | 可接受名稱 | 說明 |
| --- | --- | --- |
| 產業別 | `fin_ind`、`fin ind`、`產業別` | 值為 `F` 視為一般產業；其他值（包含空白）視為非一般產業 |

公告日可使用 Excel 日期、`YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD` 或 `MM/DD`。系統會自動去除重複公司；同一家公司出現在多個工作表或多份清單時只計算一次。

### 人力完成紀錄

檔案格式為 `.xlsx` 或 `.xlsm`，通常每位人員各有一個工作表。工作表名稱必須與 Step 1 輸入的人名相同（忽略前後空白與大小寫）。第一列必須是欄位名稱，資料從第二列開始。

必要欄位：

| 欄位 | 可接受名稱 | 說明 |
| --- | --- | --- |
| 公司碼 | `comp_id`、`公司碼`、`公司代碼`、`公司代號` | 與公司財報清單比對 |
| 財務年月 | `annyymm`、`財務年月` | 必須與目前選擇相同 |
| 季別 | `quarter`、`季別` | 必須與目前選擇相同 |
| 完成日期 | `完成日`、`完成日期` | 必須是單純日期 |

完成日期請使用 Excel 日期或 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`、`MM/DD`。像 `PYJ_0821`、`0810_X` 這類帶有文字的內容不會被視為完成日期。完成日期即使是週末也會保留，因為統計以 Excel 實際完成日期為準。

### 日期與計算規則

- 公告日會分配到下一個工作日處理；例如週五、週六、週日公告的財報，會在下週一列入可處理量。
- 忙季第一天會從開始日前一個工作日的公告資料開始計算。
- 每日會用公司碼比對「當日可處理」與「實際完成」，因此前幾日待辦可以在後續日期被消化。
- 一個人同一天優先處理非一般產業；非一般做完後，剩餘能力才會轉做一般產業。非一般能力填 0 的人不會被分配非一般工作。
- Step 4 的「尚未公告」數量會依 `fin_ind` 自動分成一般與非一般產業；尚未匯入公司清單時，才使用手動預估數量。

## 注意事項

- Excel 的欄位名稱請放在第一列，不要在上方放合併標題或說明文字。
- 更換季度或重新匯入檔案後，請重新匯入公司清單與人力完成紀錄。
- 所有資料保存在目前瀏覽器的 localStorage；清除瀏覽器資料會清除已保存設定。
