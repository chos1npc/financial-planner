# 忙季算盤

純前端的財報忙季人力與完工預估工具。資料只保存在使用者的瀏覽器，不需要後端、帳號或資料庫。

## 功能

- 預估模式：以歷史 T 日為基準，把歷史每日財報量映射到本季，計算人力是否足夠、最少人力與預估清完日。
- 即時計算：依每天實際收到量、完成量、剩餘預計來量與目前產能，即時估算能否如期完成。
- CSV 匯入與結果匯出。
- 自動儲存在瀏覽器的 localStorage。

## 計算口徑

- T 日使用工作日計算；往前或往後數時跳過星期六、星期日，再用相同的工作日差映射到本季日期。
- 每日有效產能 = 人數 × 每人每日速度 × 有效工時率。
- 工作量只能在收到當日或之後處理，不會把淡日未使用的產能累積到忙日。
- 即時模式的待處理總量 = 期初未完成 + 累計收到 − 累計完成 + 預計後續還會收到。

## 本機執行

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages

把專案推送到 GitHub 的 `main` 分支後，到 repository 的 **Settings → Pages → Build and deployment**，將 Source 選為 **GitHub Actions**。之後每次推送都會自動重新部署。
